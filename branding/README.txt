Place your custom application icon PNG file here.

The installer will automatically:
1. Find the first PNG file in this folder
2. Install it to system location: /usr/share/pixmaps/scc-digital-signage.png
3. Create system desktop file: /usr/share/applications/scc-digital-signage.desktop
4. Follow Freedesktop/Ubuntu standards for application registration

Example: SCC Digital Signage.png

Supported formats: PNG (recommended for Linux desktops)

Note: The icon will be renamed to lowercase with hyphens (scc-digital-signage.png) when installed system-wide.
